**Project rooms for founder-operators.**
Describe an outcome. Get a recommended crew of specialist AI agents. Invite people into the same orbit. Bring in human talent when the work needs a person.
Decillion is not a chatbot and not an agent framework. The unit of work is the project.

## What we build
Specialist agents, shared project rooms, and a path to hire people into the same workspace — so a company can staff work, not another AI seat.
Public repositories for this organization live on the **Repositories** tab. Pin the ones you want featured from **Settings → Profile → Pinned**.
## Open source & contributions
We welcome issues and pull requests on public repositories that accept them. Before opening a PR:
1. Read that repository’s `README` (and `CONTRIBUTING` if it has one).
2. Search existing issues so you are not duplicating work.
3. Keep the change focused and include enough context for review.
Security reports: email **support@decillionai.com** — do not file public issues for vulnerabilities.
